Privacy policy

finance-stack personal is a private application used only by its owner for their own finances. It has no other users.

What it accesses

With the owner's consent it uses the Gmail API with the read-only scope (gmail.readonly) on the owner's own Gmail account, and only processes payment receipt emails (for example from PayPal) to record the owner's own transactions.

How data is used and stored

  • Data is stored only on the owner's private, self-hosted server, reachable only over the owner's VPN.
  • Data is never sold, shared with third parties, used for advertising, or used to train AI models.
  • The app cannot send, delete or modify emails.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
